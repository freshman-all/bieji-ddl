# 别念了 (StopTalking) 正式版

这是支持账号、云端同步和服务端 AI 的生产版本工程。

## 已包含

- Supabase 邮箱登录与注册
- 本地会话保存与自动刷新
- 用户任务和主题云端同步
- 每 5 秒自动拉取云端更新
- 用户数据隔离 RLS
- 关键词、桌宠、模式等用户设置同步
- 服务端 AI Edge Function
- AI 每日 30 次限额
- 服务端模型密钥
- 正式版全部 1.4 功能
- 云服务未配置时自动退回本地演示模式

## 文件

- `index.html`：网页
- `style.css`：样式
- `app.js`：业务逻辑
- `cloud.js`：账号、登录门禁与 Supabase 云同步接口
- `cloud-config.js`：Supabase 项目配置
- `sw.js`：离线应用缓存
- `supabase/migrations/001_initial.sql`：数据库表、权限和同步函数
- `supabase/functions/parse-notice/index.ts`：AI 服务端接口
- `PRODUCTION_DEPLOY.md`：正式部署步骤

## 当前状态

云端配置为空时，页面使用浏览器本地账号系统：必须先注册或登录，密码使用 PBKDF2-SHA256 加盐保存，不同账号的数据相互隔离。第一次成功打开网页后会安装离线缓存，断网后仍可重新打开并继续使用。

完成 `PRODUCTION_DEPLOY.md` 中的 Supabase 配置后，同一账号可以在不同设备之间同步。

## 云端账号说明

当前 `cloud-config.js` 仍使用本地演示配置。接入 Supabase 项目后，把 Project URL 和 anon public key 填入 `cloud-config.js`，并将 `enableCloud` 改为 `true`，即可启用登录和跨设备同步。

## 1.7

- 整站登录门禁：未注册或未登录时不能进入任务页面
- 注册和登录支持自定义头像，个人板块中可以随时更换
- 本地密码使用 PBKDF2-SHA256、随机盐和 210,000 次迭代保存
- 同一浏览器的不同本地账号使用独立数据空间，切换账号不会串任务
- 新增三套外观：深色航站、像素田园、轨道画廊
- 轨道画廊包含衬线大字、滚动进度和环形轨道动效，适配手机与电脑
- 原创矢量桌宠“云龙”和“团子”：云龙原创节奏舞，团子原创合成笑声
- 桌宠可以从任意部位拖动，双击互动，位置和设置会保存
- 专注航线继续使用原创航线计时视觉，不与第三方角色或音频素材混用
- 新增 Service Worker 离线缓存，已访问用户在断网后仍可重新打开
- 完成注册、头像、主题、桌宠、刷新保持、账号隔离和离线重载回归测试
